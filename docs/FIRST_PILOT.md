# 第一轮真实互通：范围与接入准备

[简体中文](FIRST_PILOT.md) | [English](en/FIRST_PILOT.md)

日期：2026-10-20。用户已确认按小范围推进。本文确定首轮边界，不代表真实对端已接入。

## 产品定位

双方继续与各自的专属 Agent 交流。AB 在需要跨人沟通时连接双方 Agent，传递获准共享的信息并保留任务通信状态。工作与生活均属于长期范围；AB 不替代各自的 Agent，也不要求用户改到 AB 聊天。

## 首轮范围

- 两个人：用户与 Wright。
- 一个双方获准使用的共同项目、一项任务。
- 从已有 Agent 发起交接，附任务说明、GitHub Issue／PR 引用和讨论对应的代码版本。
- 完成一次交接及至少两轮澄清／答复；启动后无需人工搬运中间消息。
- 可区分等待接收、处理中、已回复、失败与停止；接收不等于已接手。
- 本轮仅交换信息与建议，开发修改仍按原有方式完成。GitHub 写入、自动修改代码、正式审批、合并与发布不纳入本轮自动执行。

进度反馈是首轮能力，独立网页进度台不是本轮必要条件。讨论引用不自动授权读取整个仓库或私人对话；各侧用自己的权限准备可分享内容。

## 当前证据

Mac 侧本地收件器已验证三轮真实 Codex 回复、会话续接、停止／重启与去重；对方仍是模拟 Wright。它是独立后台 Codex 会话，不等于已接入当前桌面聊天。真正跨机器与双方真实 Agent 互通尚未验证。

## 对端条件与待验证项

用户已转达 Wright 可使用 Windows Codex、运行 CLI 和连接器。首轮选择局域网 HTTPS 中转，不需要公网服务器；参见[接入说明](LAN_PILOT.md)。具体版本、LAN 可达性与真实执行仍需对端验收。

1. Wright 是否使用 Windows 桌面 Codex，以及本机 `codex --version` 能否运行。
2. 是否能在双方在线时运行本地连接器，能否完成本机 Codex 登录并执行通信任务。
3. 一项双方愿意用于试验的任务及可共享上下文；首轮可继续使用无敏感信息的演示任务。

不收集 Wright 的登录凭证、令牌或私有配置。用户转交确认结果后，再核查兼容性和连接方式；仅有产品名不能确认接口已可用。

## 推进顺序

1. 复用 Mac 收件器，核实 Windows 条件。
2. 给出与双方条件匹配的传输和配对方案，再实现真实对端连接。
3. 先验证一来一回，再验证两轮、断线后恢复和重复消息。
4. 记录双方人工转交次数、纠正次数、等待与失败；通过后再增加 GitHub 状态同步、场景名片与细化授权，随后扩展联系人和生活场景。

协议与部署仍未锁定；本次没有开启远程服务、发送消息给 Wright，或授予修改其他项目的权限。
