## 审核修复

1. **保留并行人工改动**：模型返回后及每个执行步骤前，核对文件内容、任务 HEAD 和工作区变更；出现外部改动时停止，保留现场。提交显式限制到本任务文件，避免把别人的暂存内容一起提交。
2. **约束推送目标**：拒绝 URL 重写、pushurl、额外 HTTP 路由、receivepack、mirror 等不支持配置。推送使用明确 HTTPS GitHub URL 和专用分支，关闭重定向并强制 TLS 验证；通过本机 gh 登录获取临时、URL 范围内的凭据，不放入命令参数或持久配置。此路径仅通过注入执行器测试，未对 GitHub 实际推送或建 PR。
3. **离线取消**：本机 status/cancel 从私有任务状态确定任务，不再依赖中转服务器。远端取消仍受网络时延限制；已经开始的步骤可以完成。
4. **授权与配置一致性**：每步重新校验权限；执行期间仓库授权或 Git 配置变化时停止。自动权限撤销会阻止后续步骤。澄清后仍需按本机模式重新批准或校验自动授权。
