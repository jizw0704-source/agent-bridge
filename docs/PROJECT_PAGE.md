# 项目进展页

[简体中文](PROJECT_PAGE.md) | [English](en/PROJECT_PAGE.md)

直接用浏览器打开仓库根目录的 `project.html`。页面自包含、无第三方依赖，不需要启动 AB 服务；中英文切换、功能筛选和展开说明均可离线使用。

页面汇总项目定位、已验证／待验收／规划中的功能、六步交接流程、里程碑与下一步。运行状态是带核查时间的人工维护快照，不会从页面连接私有服务器，也不包含凭证、身份代码或私人网络地址。过期房间会根据当前时间显示到期提示。

## 如何更新

1. 先读取仓库与运行记录；运行状态可用已安装 AB Skill 的只读状态辅助脚本核查。
2. 编辑 `project.html` 中的 `snapshot`、`features`、`steps`、`history` 以及中英文 `data-zh`／`data-en` 文案。只填写核实过的非敏感信息；`checkedAt` 必须是实际核查时间，更新页面的时间不能代替运行核查时间。
3. 本地浏览器检查桌面、窄屏、中英文、功能筛选与键盘焦点；运行 `pnpm check`、`pnpm test` 和 `git diff --check`。不需要构建。
4. 提交并推送 GitHub，核对远端提交；将同一 HTML 复制到 Obsidian 项目目录，更新项目总览中的链接，并记录提交编号和验证结果。历史记录与当前状态分开维护。

临时 HTTP 预览：在仓库运行 `python3 -m http.server 8874 --bind 127.0.0.1`，访问 `http://127.0.0.1:8874/project.html`；端口占用时换空闲端口。Markdown 文档可从仓库或 Obsidian 阅读，浏览器对本地 Markdown 的显示方式各不相同。

同步的是源码与项目记录，不会自动部署 AB 服务。页面不支持直接编辑或自动双向同步，筛选／语言切换只影响当前浏览会话。

页面内的文档入口指向 GitHub，方便将单文件复制到 Obsidian 后仍可使用；离线时可在本地仓库查阅文档。
